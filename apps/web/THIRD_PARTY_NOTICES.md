# Design references and dependencies

The study-cafe frontend is an original implementation adapted to its existing API. No paid template source, screenshots, logos or template assets are bundled.

- [Shadcn Admin](https://github.com/satnaing/shadcn-admin), MIT, Copyright (c) 2024 Sat Naing: navigation shell, filterable tables and task-detail patterns.
- [Shadcn Dashboard](https://github.com/shadcndashboard/shadcndashboard), MIT: split note-list and reading-pane pattern.

These are design references, not copied source components. Settings contains reference links. Dependencies retain their upstream licenses in their installed packages: React (MIT), Lucide (ISC), Inter and Noto Sans KR (SIL Open Font License). Fonts are bundled locally by Vite. The lockfile pins dependency versions.

No 21st.dev generation, paid template, payment integration, external font CDN or analytics service is used by this frontend.
