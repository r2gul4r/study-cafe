# 원본 표기 누락과 정답 오류 구분

검증일: 2026-10-15. [PDF 이미지 검증](LIVE_PDF_VISUALS.md)에서 중간 적분식의 `dy` 누락 때문에 보류했던 문항을 개선했다. 특정 시험·과목·문항 번호를 분기하지 않는 공통 정책이다.

## 판단 기준

| 구분                                                             | 처리                                                                                                               |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 중간 풀이의 기호·철자·반복 표기 누락                             | 원문 문맥으로 의미가 하나로 정해지고, 독립 풀이·원본 최종 정답·저장 정답이 일치하며 채점에 영향이 없으면 사용 가능 |
| 잘못된 수치 등식·부호·단위·정답·선택지 대응                      | 이후 줄이나 최종 답이 맞더라도 정답 오류로 보류                                                                    |
| 문제 조건·연산자 누락, 여러 해석이 가능한 수식                   | 원본 의미가 불명확하므로 보류                                                                                      |
| 검토 결과·정확한 인용 누락, 다른 판본의 근거, 모순된 영향도 판정 | 서버에서 사용 가능 판정을 차단                                                                                     |

추출과 독립 검토에 같은 정책을 제공한다. `sourceCheck`는 문제의 명확성, 독립 계산 답, 최종 답의 일치 여부, 오류 종류·위치·원문 인용·문맥 해소·정답 및 채점 영향을 기록한다. 추출 문항의 독립 검토에서 이 결과가 없으면 보류한다. AI 생성 문항에는 기존 검토가 적용된다.

서버는 오류 인용이 제공된 원문 및 문제/정답 판본에 속하는지 검사한다. `notation_only`여도 최종 정답이나 문제 본문을 수정해야 하거나 의미·채점 영향이 있으면 허용하지 않는다. 전체 `usable=true`만으로 세부 판정의 모순을 덮지 않으며, 다른 이유로 내려진 모델의 보류도 강제로 통과시키지 않는다. 의미 판단과 계산 자체는 모델에 의존하므로 형식 검사만으로 수학적 정확성을 보장하지 않는다.

검토 결과를 문항 버전의 검토 기록에 저장하고 문제은행 상세에 근거를 표시한다. 원문 PDF·텍스트·정답표를 수정하지 않고, 기존 답안·확정 점수도 자동 변경하지 않는다. 응시 중에는 정답을 포함한 검토 기록을 제외한다. 새 독립 검토에는 이전의 사용 가능/보류 상태와 검토 의견을 전달하지 않는다. 사용자의 수동 검토에는 이전 AI 기록을 현재 판정처럼 붙이지 않는다.

## 실제 Codex 검증

기존 ChatGPT 로그인과 동일한 모델 설정을 사용했다. 추가 유료 API·OCR·새 패키지를 연결하지 않았다. 계정 사용량은 소모한다.

### 공개 PDF

MIT 18.05 Spring 2022 Exam 1의 저장된 원본 시험지 7·8쪽과 연결된 해설 이미지를 새로 추출했다. 원본은 Jeremy Orloff·Jennifer French Kamrin/MIT OpenCourseWare, CC BY-NC-SA 4.0이며 URL·원본 해시는 앞선 [검증 문서](LIVE_PDF_VISUALS.md)에 있다. 전체 시험 재검증이나 새로운 인터넷 검색 결과가 아니다.

- **5(d): 사용 가능.** 중간 이중적분의 `dy` 누락은 앞뒤 원문으로 의미가 명확하며 공분산 −5/576, 상관계수 −5/47과 채점에는 영향이 없다고 독립 검토했다. 문제에서 요구하지 않은 풀이 설명을 추가로 채점하지 않는다.
- **5(e): 사용 가능.** 적분 영역·밀도와 여러 페이지에 걸친 정답 연결도 유지됐다.
- **6번: 보류 유지.** `20 × 5 × 10^4 = 10^5`라는 원본 등식은 잘못된 수치 계산이다. 뒤의 표준편차와 최종 근삿값이 맞아도 단순 표기 누락으로 넘기지 않는다.

두 실행 모두 실제 추출 2회·독립 검토 2회, 각 4회 호출로 2문항 사용 가능·1문항 미해결이었다. 최종 실행은 promptVersion 13이며 이전 검토 의견·상태를 입력에서 제외한 상태에서도 결과가 일치했다. 대조 사례 6회를 포함한 이번 실제 호출은 **총 14회 모두 형식 성공, 시간 초과·429·재시도 0회**, 저장된 호출 시간 합은 401.745초다. [결과 JSON](evidence/live-source-quality-2026-10-15.json)에 두 실행과 최종 검토를 기록했다. 과거 후보가 중복으로 재사용될 때도 새 독립 검토를 수행하며 과거 실행 이력을 삭제하지 않는다.

### 직접 작성한 대조 사례

실제 공개 기출과 별도로 격리된 DB에서 제품의 `verify_question` 경로를 실제 Codex로 6회 실행했다. 이 자료는 원래부터 검증을 위해 작성한 텍스트이며 PDF 인입이나 기출 수집 실적이 아니다.

| 사례                                | 기대·실제 결과       |
| ----------------------------------- | -------------------- |
| 문맥이 명확한 중간 적분의 `dy` 생략 | 표기 누락, 사용 가능 |
| 중간 설명의 `prodcut` 철자 오류     | 표기 오류, 사용 가능 |
| `2+2=5`, 최종 답도 5                | 정답 오류, 보류      |
| 중간 `2×3=5`, 최종 답은 6           | 정답 오류, 보류      |
| 거리를 `20 s`로 표시                | 단위 오류, 보류      |
| `3 [missing operator] 4`            | 의미 불명확, 보류    |

6개 모두 예상 상태·오류 분류가 일치했다. 이 대조 실행은 이전 검토 입력 제외 변경 전 코드로 수행했으며, 모든 후보가 최초 검토여서 이전 AI 판정은 없었다. 해당 변경 후에는 공개 PDF를 재실행하고 자동 검사로 검토 입력에서 이전 상태가 제외되는지 확인했다.

## 회귀 검사와 재현

- `pnpm check`: **106개 통과**, 서버·웹 타입 검사 통과. 새 14개 검사는 허용 조건, 모순된 영향도, 누락/허위/다른 판본 인용, 모델 보류 유지, 검토 기록 저장과 응시 전 답 비공개를 확인한다. 모의 에이전트의 계약 검사와 실제 모델 성능을 구분한다.
- `pnpm build`: 통과. 격리 브라우저에서 사용 가능 상태와 표기 누락 근거 안내가 함께 보이는 것을 확인했다.
- 작업 중 종료된 공부방 서버는 기존 DB의 작업 7개가 모두 완료 상태임을 확인한 뒤 최종 코드로 다시 실행했다. 기존 결과 25문항·34/39점·보류 0개가 유지됐다. 사용자의 공부방에는 검증 문항을 넣지 않았다.
- 초기 기존 테스트 1개는 새 검토 계약이 없는 모의 응답으로 보류됐고 테스트 fixture를 보완했다. 추가 테스트의 타입 선언 오류도 수정 후 전체 검사를 통과했다. 한 차례 명령이 자동 승인 검토 한도로 실행 전에 차단됐으나 정상 승인 경로 재실행으로 해소됐고 우회·추가 결제는 없었다.

```powershell
pnpm exec tsx scripts/live-source-quality.ts --live
pnpm exec tsx scripts/live-pdf-extraction.ts --live --phase=extract --resume=<기존-PDF-검증폴더> --new-extraction --pages=7,8 --max-calls=14
```

`--live`가 없으면 대조 스크립트는 AI를 호출하지 않는다. 실제 실행은 성공/실패·판정을 로컬 JSON에 저장하며, Git에는 전체 원본 PDF·검증 DB·인증정보를 포함하지 않는다. 긴 정답표·스캔 OCR·다른 과목의 다양한 오류에 대한 일반 정확도, 원본 오류의 수동 정정 확정은 후속 과제다.
