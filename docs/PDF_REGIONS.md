# PDF 문항 영역과 입력 중복 제거 · 2026-10-15

## 구현한 흐름

문제은행 → 문항 상세 → **PDF 문제 표시 영역 설정**에서 원본 위를 드래그하거나 백분율을 입력한다. 문제 조건·공통 지문·그래프·보기가 모두 들어가도록 선택하고 새 버전으로 저장한다. 한 페이지당 한 사각형, 한 문항당 최대 8개 영역이다. 페이지 전체 표시로 되돌릴 수도 있다.

서버는 저장된 원본 PDF의 같은 판본·페이지를 직접 렌더링한다. AI가 새 그림을 그리거나 외부 경로를 읽지 않는다. 원본 페이지와 정확한 인용은 `visualEvidence`에, 잘라낸 이미지·원본 이미지·정규화 좌표는 `learnerRegions`에 보관한다. 페이지 및 영역 캐시는 해당 source revision에 연결되고 백업의 자산 검증에 포함된다.

변경은 항상 새 문항 버전이며 검토 대기로 시작한다. 응시자에게는 선택 영역만 첨부하고 원본 페이지와 정답표는 독립 검토에 제공한다. 원본 일치·필수 내용 완전성·정답 노출 없음을 모두 확인해야 AI 검토가 통과한다. 검토 결과와 이유를 문항 상세에도 저장·표시한다. 기존 시험 스냅샷·점수·이전 승인 버전은 바꾸지 않는다.

다른 문항/정답표를 표시 영역으로 지정하거나 좌표·자산 출처를 위조하는 경우, 손상된 이미지, 중복 페이지, 오래된 문항 버전은 거부한다. 원본 정답 오류 정정 이력이 있는 문항은 문제 불변 조건을 유지하기 위해 영역 변경을 허용하지 않는다. 추출 시에는 원본 페이지를 먼저 보존하며 자동 영역 추천은 아직 구현하지 않았다.

## 요청 입력

추출 요청에서 동일한 `segmentId`의 원문을 `segments`, `adjacentSegments`, `sourceContext`, `answerSegments` 전체에 한 번만 넣는다. `sourceHeaderId`, `sourceContextIds`, `answerSegmentIds`가 여러 역할의 위치를 가리킨다. 문항 앵커는 계속 `segments` 안에 있어야 한다. 서로 다른 판본의 같은 문구는 합치지 않으며 인용문·그래프·원본 이미지·서버 검증 범위를 줄이지 않는다.

`materialDelivery`에 고유 원문 글자 수와 제거한 중복 글자 수를 기록한다. 이번 최적화는 **중복 텍스트 제거**다. 전체 페이지 이미지 수·실제 모델 토큰 수·시간 초과 감소를 보장하지 않는다. 이미지 후보의 선택적 전달과 누락 페이지 추가 요청은 다음 작업이다.

## 실제 Codex 검증

- MIT 18.05 Spring 2022 Exam 1의 그래프 문항을 별도 복사 DB에서 검토했다. 그래프·조건·질문을 모두 포함한 영역은 사용 가능, 그래프가 빠진 영역은 `complete=false`로 보류됐다. 실제 호출 2회, 각 3개 이미지(문제 원본·정답 원본·선택 영역).
- 첫 정상 영역 검토 자체는 통과했지만 검증 스크립트가 문항에 아직 저장하지 않던 `visualCheck`를 읽어 중단했다. 검토 결과 저장을 보완하고, 이미 성공한 호출을 재실행하지 않고 두 번째 사례로 재개했다. 최초 결과와 세션 이력을 보존했다.
- 중복 제거 후 MIT 6.042J 2008 final의 17쪽 문제와 별도 13쪽 정답을 다시 추출·검토했다. 실제 호출 2회로 연결·정확한 인용·정답 이미지 제외를 확인했다. 원문 텍스트 13,161자 → 11,472자, 중복 1,689자(약 12.8%) 제거. 추출 이미지는 10개로 유지됐다.
- 이 문항은 원문 조건 및 해설 관례의 불확실성으로 계속 검토 대기다. 원본 정답이 확실히 틀렸다고 단정하거나 검색 실패로 집계하지 않는다.
- 이번 실제 호출은 총 4회 모두 형식 응답 성공. 기존 ChatGPT 로그인만 사용했고 추가 과금 API는 없다. 계정 이용량은 소모한다. [근거 JSON](evidence/live-pdf-regions-2026-10-15.json).

## 재현

```powershell
node --import tsx scripts/live-question-regions.ts --live --fixture=<완료된-live-pdf-extraction-폴더>
node --import tsx scripts/live-question-regions.ts --live --resume=<생성된-live-regions-폴더>
```

이 스크립트는 지정된 공개 PDF 검증 fixture를 새 폴더에 복사하며 최대 2회만 호출한다. 실제 공부방을 입력하지 않는다. 일반 CI는 모의 에이전트와 직접 만든 PDF로 출처·좌표·손상·버전 충돌·사용자 첨부 분리·완전성/정답 노출 검토·백업 보존을 검사한다.

브라우저에서 백분율 입력·드래그·새 버전 저장·이전 버전 보존을 확인했다. 새 영역을 저장한 버전은 다시 검토 대기이며 과거 실제 AI 승인을 그대로 물려받지 않는다. 390px 화면의 문서/모달 가로 넘침이 없고 영역 선택기가 하나만 나타나는 것을 확인했다.

공개 자료 및 이용 근거는 [기존 PDF 검증](LIVE_PDF_EXTRACTION.md)과 [긴 정답표 검증](ANSWER_RETRIEVAL.md)을 따른다. 제품 코드에 시험/과목별 분기는 없다.
