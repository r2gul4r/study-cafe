# 실제 PDF 이미지·다중 페이지 정답 검증

후속 [원본 오류 영향도 검증](SOURCE_QUALITY.md)에서 5(d)의 중간 `dy` 누락은 허용하고 6번의 수치 등식 오류는 보류하도록 개선했다. 아래 내용은 이전 실행 당시의 기록이다.

검증일: 2026-10-15. 앞선 [텍스트 PDF 검증](LIVE_PDF_EXTRACTION.md)의 보류 항목을 개선한 후속 작업이다. 같은 MIT 18.05 Spring 2022 Exam 1 시험지 11쪽·해설 6쪽의 저장 원본을 사용했다. 저자는 Jeremy Orloff와 Jennifer French Kamrin, 제공처는 MIT OpenCourseWare, 이용 조건은 CC BY-NC-SA 4.0이다. 원본 PDF·페이지 이미지·전체 모델 응답은 격리된 로컬 검증 폴더에만 보관한다.

## 구현

1. 저장된 원본 PDF의 해시를 확인하고 PDF.js의 Node 캔버스로 필요한 페이지를 PNG로 렌더링한다. 최대 긴 변 2,000px, 배율 2.5이며 이번 자료는 1,530×1,980px이다. 페이지·원문 버전·이미지 자산 ID를 연결해 캐시하고 기존 백업에도 포함한다. 모델이 만든 경로나 URL을 열지 않는다. 렌더러가 없거나 이미지가 손상됐으면 오류를 내며 성공으로 처리하지 않는다.
2. Codex `turn/start`에 텍스트와 이름표가 붙은 `localImage`를 함께 전달한다. 설치된 프로토콜 타입과 [공식 문서](https://learn.chatgpt.com/docs/app-server)의 이미지 입력을 확인했고 실제 호출로 작동을 검증했다. 기존 ChatGPT 로그인만 사용하며 추가 유료 API·OCR·임베딩 서비스를 연결하지 않았다. 이미지 입력도 기존 계정 사용량을 소모한다.
3. 이미지가 제공된 PDF 문항은 `visualTranscription=true`로 표시하고 원래 문구·언어와 수식을 읽을 수 있는 일반/유니코드 표기로 옮긴다. 원본 이미지와 구간을 `visualEvidence`로 보존한다. 텍스트 출처 인용은 여전히 원문과 문자 그대로 일치해야 한다. 이미지가 없는 자료는 기존의 연속 원문 문구 검사를 유지한다.
4. 독립 검토에도 사용한 원본 이미지를 전달한다. 문구·수식의 충실성, 그래프와 공통 지문의 완전성, 응시자에게 정답 이미지가 노출되지 않는지를 모두 확인해야 사용 가능하다. 질문 본문의 그래프를 해설이나 지식으로 추측해 대체하지 않는다. 정상 인용이 있어도 내용이 틀리면 보류한다.
5. `sourceMatch.answerContinuationEvidence`로 번호가 인쇄된 정답 구간 이후 최대 4개 연속 구간을 연결한다. 같은 원문 버전·순서·빠짐없는 연속성을 서버가 검사하고, 상위 문제와 소문항 및 실제 답의 연결은 별도 모델 검토에서 확인한다. 단순히 인접했다는 이유로 정답을 연결하지 않는다.
6. 문제 이미지 자산만 응시 문항의 `requiredAssetIds`에 포함한다. 정답 이미지 근거와 연결 정보는 제출 전 응시 데이터에서 제외한다. 문제은행·결과·응시 화면에서 인증된 PNG 미리보기와 확대 링크를 제공하며, 이미지 복원 표시를 남긴다. 다른 그래프를 가진 동일 문구의 문항은 중복으로 합치지 않는다.
7. 추출 API의 선택적 `pdfPages`로 필요한 페이지만 다시 처리할 수 있다. 원문 앞뒤 판본과 인접 문제 문맥은 유지한다. 한 응답 최대 2문항, 정답 후보 최대 10구간, 이미지 최대 16개, 응답별 체크포인트와 기존 오류 재개 정책을 유지한다.

## 실제 실행 결과

문제 2·6·7·8쪽의 8개 소문항을 두 번 새로 추출했다. **최종 실행은 6개 사용 가능·2개 미해결**이며, 사용 가능 6개 모두 실제 Codex의 새 독립 검토를 통과했다. 기존 보류 중 **1(a)·5(c)·5(e)의 3개를 해결**했다. 원본 해설 문제가 있는 6번은 유지했고, 최종 실행은 5(d)의 중간 계산 표기 누락도 보수적으로 보류했다. 다른 목표나 운영 공부방에 검증 문항을 추가하지 않았다.

| 문항       | 최종 결과 | 대조 내용                                                                                       |
| ---------- | --------- | ----------------------------------------------------------------------------------------------- |
| 1(a)       | 사용 가능 | 원본 세 곡선과 같은 축척을 읽어 최대 분산 X 확인. 설명을 요구하지 않는 기준 유지                |
| 1(b)       | 사용 가능 | 합집합 0.75·조건부 확률 5/6, 수학 기호를 원본 이미지와 대조                                     |
| 5(a), 5(b) | 사용 가능 | 주변밀도 5/4−x/2 및 5/4−y/2, 독립 아님                                                          |
| 5(c)       | 사용 가능 | 해설 3→4쪽 연결, E[X]=11/24·Var(X)=47/576                                                       |
| 5(e)       | 사용 가능 | 적분 영역 R의 첨자 복원, 0≤x,y≤1 안에서 x<y<x+0.1, 피적분함수 5/4−xy. 수치 계산을 강제하지 않음 |
| 5(d)       | 미해결    | 해설 중간의 두 번째 이중적분에서 dy 누락. 최종 답은 정확하지만 원본 오류 정책을 보수적으로 적용 |
| 6          | 미해결    | 원본 해설의 분산 계산과 표준편차가 모순                                                         |

실제 호출은 **2회 실행·총 21회(형식 성공 20회·형식 오류 1회)**, 저장된 호출 시간 합계 709.465초다. 첫 실행은 10회, 최종 실행은 **11회 전부 형식 성공**이며 시간 초과·429는 이번 두 실행에서 관찰하지 않았다. 과거 시간 초과 문제가 모두 해결됐다는 뜻은 아니다. 최종 지시는 promptVersion 11이다. [근거 JSON](evidence/live-pdf-visuals-2026-10-15.json)에 호출·이미지 해시·실패·실제 독립 검토를 기록했다.

첫 이미지 실행에서 그래프 1(a), 정답이 해설 3→4쪽으로 이어지는 5(c), 적분 영역 첨자가 손실됐던 5(e), 비교용 5(d)가 실제 독립 검토를 통과했다. 5(e)는 해설의 영역 그림과 4→5쪽 적분식 연결도 확인했다. 주관식 배점 합계 오류 1회는 스키마 검사가 차단하고 한 번 보완했다. 같은 실행의 1(b)·5(a)·5(b)는 이미지 표기를 옮기면서 텍스트 모드로 표시해 거부됐다. 원문 검사를 무조건 완화하지 않고, PDF 이미지 추출 모드를 명시하도록 지시를 수정한 뒤 같은 네 페이지를 다시 실행했다.

6번은 원본 해설에 `20 × 5 × 10^4 = 10^5`, 표준편차 `10^3`이 함께 인쇄된 모순이 있다. 실제 곱은 `10^6`이다. 모델이 페이지 이미지에서 이 충돌을 확인했고 정상 기출로 자동 저장하지 않았다. 원본 정답 오타의 수동 정정·확정은 이번 작업의 범위가 아니다. 5(d)는 첫 이미지 실행의 독립 검토에서 최종 답이 정확하므로 통과했으나 최종 새 추출은 dy 누락으로 보류했다. 이 판단 변동과 예전 사용 가능 후보를 모두 보존했으며 자동으로 원본을 수정하거나 기존 문항의 상태를 일괄 취소하지 않았다. 경미한 중간 표기 오류와 정답 충돌을 구별하는 검토 정책은 후속 개선점이다.

## 검사와 화면 확인

- 신규 5개를 포함한 테스트 92개, 백엔드·프론트 타입 검사와 빌드가 통과했다. 이미지 RPC 전송, 실제 PDF 렌더링·재사용·DB 재개·백업, 서로 다른 그래프의 중복 분리, 원문/이미지 조작과 다른 목표 차단, 독립 이미지 검토 누락 시 보류, 번호/판본/연속성 검사와 정답 이미지 제외를 확인했다. 자동 테스트의 모델은 모의 에이전트이며 실제 모델 성능과 구분한다.
- 격리 복사본의 브라우저에서 1(a) 원본 그래프가 실제 PNG로 로드되는 것과 5(e)의 공통 지문·문제 이미지 2개 및 복원된 적분 영역 표기를 확인했다. 문제 원본만 첨부돼 있고 정답 근거는 별도 원문 대조 영역에 남는다.
- 운영 공부방의 기존 답안·시험 스냅샷을 수정하지 않았다. 같은 DB로 서버를 재시작한 후에도 25문항·34/39점·보류 0개가 유지됐다. 이미지 모드가 과거 텍스트 문항을 자동으로 덮어쓰는 마이그레이션은 없다. 동일한 기존 문항을 재사용한 경우에도 이번 실행에서 새 독립 검토를 수행했다.

## 재현과 한계

```powershell
pnpm exec tsx scripts/live-pdf-extraction.ts --live --phase=extract --resume=<기존-PDF-검증폴더> --new-extraction --pages=2,6,7,8 --max-calls=30
pnpm exec tsx scripts/live-pdf-extraction.ts --live --phase=audit --resume=<기존-PDF-검증폴더>
```

이미지 없는 전체 스캔 PDF의 OCR 인입은 아직 지원하지 않는다. 이번 개선은 텍스트 PDF에 있는 그래프·수식·표 배치의 보완이며, 그래프 부분만 자동 잘라내거나 모든 LaTeX 수식을 조판하는 기능은 아니다. 한 페이지 전체 이미지를 제공하므로 모델이 답지가 함께 인쇄된 원문을 안전하게 분리할 수 없으면 보류한다. 아주 긴 정답표의 검색, 다섯 구간을 초과하는 답의 연결, 복잡한 문항의 시간 초과와 시각 해석 정확도는 여전히 제한이 있다. 이번 재검증은 지정한 4개 페이지의 범위이며 전체 시험을 최종 코드로 다시 추출한 검사와 구분한다.
