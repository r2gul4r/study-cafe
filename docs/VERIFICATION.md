## 실제 연결 검증

실제 설치된 Codex로 계정 상태 조회, 구조화 추론, 웹 검색을 확인했다. 공개 HTML 다운로드도 실제 네트워크에서 확인했다. 검색 결과는 공식 Python 문서이며, 계정이 로그인되어 있다는 사실만으로 추론 성공을 추정하지 않았다.

2문항 연결 검사에서 자체 작성 학습 자료를 근거로 객관식 1개와 주관식 1개를 생성하고, 각각 별도 검토 호출을 통과했다. 모범답안을 제출하여 객관식 채점과 실제 Codex 주관식 평가가 완료됐으며 보류 문항은 없었다.

**25문항 전체 검사도 통과했다.** 자체 작성 Python 학습 자료에서 실제 Codex가 객관식 20개와 주관식 5개를 생성했고, 각 문항은 별도 검토 호출을 거쳐 시험에 저장됐다. 전체 답안 제출 후 주관식 5개를 실제 모델이 고정 기준으로 채점했다. 확인 점수는 34/34점, 보류 0개다. 배점은 문항별 기준의 합계이므로 문항 수와 다르다. 이 검사는 모범답안을 입력한 연결 검사이며 다양한 학생 답변의 채점 정확도 평가가 아니다. 생성 문항 중 3개의 본문·보기·근거·검토 결과도 직접 읽어 확인했다.

이어서 같은 문제은행으로 검증용 재응시를 만들고 틀린 보기를 제출했다. 실제 Codex가 해당 응시를 근거로 개념별 오답 요약을 저장했고, 원본과 같은 계열의 새 변형 문항을 생성했다. 변형 문항의 별도 검토가 통과했고 복습 일정 저장도 확인했다.

실제 외부 시험 사이트별 기출 수집, 개별 자격시험의 범위·정답 정확성, 장기 학습 효과를 모두 검증한 것은 아니다. 네트워크 검색과 다운로드 성공, 통제된 자료 처리 성공을 구분한다. 자동 검토가 문항 정확성을 보장하지 않으므로 사용자의 정정 경로를 유지한다.

## 현재 확장 경계

- 프론트엔드 1차 구현과 주요 브라우저 흐름 검증을 완료했다. 현재 화면 범위와 미검증 항목은 [FRONTEND.md](FRONTEND.md), 작업 인수인계는 [PROJECT_STATUS.md](../PROJECT_STATUS.md)를 참고한다.
- 입력은 텍스트·HTML·텍스트 PDF다. 스캔 OCR, 청해 재생, 복잡한 표·수식 복원, 코드 실행 채점은 후속 범위다.
- 공식 모의시험의 총 문항 수와 시간은 저장한 근거와 대조한다. 시험별 섹션 규칙·음성 진행을 재현하는 엔진은 없다.
- 실전 자료별 수집 조건과 페이지 구조는 다르다. 수집 불가·링크 전용·미확인 문항을 구분해서 반환한다.
- 모델 품질·응답 시간·사용 가능량은 계정과 모델에 영향을 받는다. 학습 기록은 로컬이며 모델 추론과 웹 검색에는 온라인 연결이 필요하다.
- OpenAPI에는 경로와 입력 스키마를 생성했다. 응답 객체는 API 가이드와 도메인 반환값을 함께 참고하며 모든 응답의 정적 JSON Schema까지 정의한 것은 아니다.
