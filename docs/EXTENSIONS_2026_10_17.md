# 청해 제외 확장 · 2026-10-17

요청 범위는 청해를 제외한 잔여 구현과 검증이다. 별도 유료 API 없이 기존 Codex 계정과 로컬 런타임을 사용한다. home에서 구현한 코드와 검증 기록을 함께 관리하며, 최신 커밋과 develop 통합·원격 반영 상태는 Git의 실제 브랜치 참조로 확인한다.

## 구현

- **Python 실행 채점**: 주관식 중 Python 문항 수를 지정한다. 표준입출력 계약·공개 예제·비공개 테스트를 저장하고, 독립 AI 검토와 모범 코드의 실제 실행을 모두 통과해야 사용 가능하다. 학습 화면에서 공개 예제를 실행하고 제출 후 전체 테스트를 동일 배점으로 채점한다. 수동 확정·정정·동시 평가를 보호하고, 실행기 초기화 실패는 0점 대신 보류한다. 코드·실행 결과·복습 기록은 DB에 남는다.
- **실행 경계**: Pyodide 314.0.7/CPython 3.14를 Deno 2.9.6 자식 프로세스에서 테스트마다 실행한다. 초기화 후 파일 읽기 권한을 회수하고 네트워크·쓰기·환경 변수·하위 프로세스·FFI·외부 import 권한을 차단한다. 테스트 실행 1~10초, 초기화 20초, 출력 32KiB 제한이다. 호스트 메모리의 OS 수준 상한이나 공개 다중 사용자 코드 실행 서비스의 격리를 구현한 것은 아니다. 표준 라이브러리도 WASM에서 제공되는 범위만 사용하며 pip·외부 패키지는 지원하지 않는다.
- **복습**: 원래 FSRS 예정일과 당일 완료를 구분한다. 같은 목표 시간대의 오늘 성공한 동일 계열은 오늘 복습에서 제외하지만 간격을 중복 갱신하지 않는다. 복습 시험은 실제 남은 계열 수로 구성한다. 다음 날짜의 유효 복습은 기존 간격 갱신 정책을 따른다.
- **PDF 전달**: 원문 텍스트·원본·캐시를 보존하면서 실제 첨부 이미지만 선택한다. 초기 4페이지, 필수 최대 16페이지, 누락 이미지 추가 요청 최대 2회다. 앵커·직접 정답·명시 요청을 보존한다. 미전달 이미지 근거·다른 자료·반복 요청은 거부하거나 미해결로 남긴다.
- **영역 추천**: 원본 문제 이미지만 읽는 별도 작업이 좌표를 제안한다. 제안만으로 문항을 바꾸지 않는다. 화면에서 확인·적용하고 새 버전으로 저장한 뒤 기존 독립 이미지 검토를 거친다. 오래된 버전/다른 구간의 제안을 거부한다.
- **OCR**: PDF 가져오기에서 영어·한국어·일본어 중 하나를 선택한다. 텍스트가 없는 페이지를 로컬 Tesseract.js 7 모델로 읽으며 원본 PDF, 페이지, 신뢰도, 시각 검토 필요 표시를 보존한다. 한 요청 최대 20개 스캔 페이지·페이지 인식 45초 제한이다. 텍스트가 일부 있는 혼합 페이지를 자동 전체 OCR하지 않으며 수식·필기·혼합 언어 정확도를 보장하지 않는다. OCR 근거는 독립 검토에 원본 이미지를 함께 보낸다.
- **섹션**: 이름·문항 수·시간·개념을 지정한다. 전체 합계를 검증하고 현재 섹션만 답할 수 있다. 이전 섹션으로 되돌아갈 수 없고 중복 이동을 거부한다. 일시정지·재시작과 만료 후 다음 섹션/최종 제출을 DB v3에서 복구한다. 묶음 문항은 섹션을 가로질러 배치하지 않는다. 공식 모드는 저장된 공식 구성과 일치해야 하지만 모든 시험의 특수 규칙을 탑재한 것은 아니다.
- **실패 복구**: 작업 상세에서 자료 부족·검토 보류·계정/로그인 제한·실행기 문제별 다음 행동으로 연결한다. 자료/범위가 바뀐 작업은 새 작업으로 안내한다. 생성 문항의 단순 수치/표현 중복을 탐지하고 신규 문제 배점은 정수로 제한하되, 추출·수동 문항의 소수 배점과 엄격한 합계 검사는 유지한다.

## 발견해 수정한 문제

신규 생성에서 rubric 기준마다 0.01이 붙어 합계가 어긋나는 실제 출력이 반복됐다. 프롬프트 강화와 숫자 하한 조정만으로는 해결되지 않아 그 임시 변경을 제거했고, 신규 생성 스키마에 정수 배점 계약을 적용했다. 기존 실패 기록과 완성된 20문항을 유지한 채 재개했다.

CSS 최종값 문제에서 계산법을 묘사한 기준을 ‘풀이 과정을 요구함’으로 잘못 해석해 보류한 사례가 있었다. 명시적 설명 요구와 정답값의 계산법 묘사를 구분하도록 기준 검토 정책을 보완했다. 새로운 별도 채점 작업으로 확인했으며 기존 평가·실패 이력을 덮어쓰지 않았다. 설명이 실제로 요구된 대조 문항의 감점과 부당한 기준의 보류도 재검증했다.

검증 스크립트의 첨부 조회 호출/실행 경로 오류는 고친 뒤 새 빈 폴더에서 다시 복원했다. 제품 복원 함수의 오류와 구분한다. `checklist-vibe` CLI가 설치되지 않아 해당 CLI 검사는 생략했고 스킬의 검토 절차와 프로젝트 타입/테스트/빌드로 확인했다.

추출 대조에서 원문의 `a. margin`을 그대로 보존한 유효 정답이 `margin`과 문자열이 다르다는 이유로 실패했다. 직접 작성한 원문과 정답표가 일치함을 확인하고, 검증기는 정확한 정답 내용 또는 해당 원문의 보기 기호를 보존한 형태만 허용하도록 고쳤다. 제품의 원문·정답은 변경하지 않았다. 최종 범위 편집에서는 공식 섹션을 보존·편집하고 범위 밖 개념/합계 오류를 거부하도록 보완했다.
