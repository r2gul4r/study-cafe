# 실제 Codex 자료 수집·출제 검증 · 2026-10-15

기존 ChatGPT 관리 로그인의 Codex App Server로 **일반 학습·실무 역량·시험형 목표 3개**를 같은 격리 DB에서 검증했다. 실제 웹 조사 → 이용 근거 확인 → 본문 다운로드·구간 저장 → 생성 → 독립 검토 → 시험 준비를 실행했다. 추가 결제·API 키·유료 검색·임베딩·대체 공급자는 추가하지 않았다. 모델은 기존 설정을 사용했고 정확한 모델명은 기록하지 않았다. 추론 강도는 `medium`이다.

**생성 12문항 전부** 저장된 해당 목표의 원문을 정확하게 인용했고, 독립 검토 뒤 시험 `ready`·문항 `usable`을 확인했다. 인용이 다른 목표의 자료로 연결되지 않았으며 AI 생성 문항을 기출로 표시하지 않았다. 천문·통계는 실제 모델 입력의 자료 소속도 검사했고 CSS는 생성 결과의 인용을 DB와 대조했다. 특정 시험 이름이나 과목명에 따른 제품 분기는 추가하지 않았다.

이 검사는 호출량을 제한한 **목표당 4문항 표본**이다. 앱의 기본 25문항 설정은 그대로다. 범위·참고 URL을 검증 코드에서 미리 정했으므로 목표를 자유 입력하는 첫 화면이나 범위 자동 설계까지 새로 확인한 검사는 아니다. 통계 목표도 실제 자격시험의 범위·기출 검증이 아닌 개인 학습 평가다.

수집·이용 판단의 근거:

- MDN 설명 자료의 저작자 표시는 MDN contributors이며 [MDN 이용 안내](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Attrib_copyright_license)의 CC BY-SA 조건을 확인했다.
- Learning Statistics with R의 저자는 Danielle Navarro이며 [책의 안내](https://learningstatisticswithr.com/index.html)에 CC BY-SA 4.0이 명시돼 있다.
- USNO는 [이용 안내](https://aa.usno.navy.mil/about/PrivacyNotice)의 공개 정보 조건을 확인했다. 사진의 별도 저작권 표시는 제외했으며 텍스트만 수집·출제에 사용했다.
- NASA와 OpenStax의 이용 조건에 대해 이번 에이전트가 충분한 사용 근거를 확보하지 못한 결과는 `link_only`로 유지했다. NASA 자료 전체가 AI에 금지됐다는 판정이 아니다. 수집을 위해 이용 조건을 덮어쓰거나 제한된 원문의 미러를 사용하지 않았다.

본문 전체나 원격 이미지는 저장소에 싣지 않았다. [근거 기록](evidence/live-materials-2026-10-15.json)에는 실제 생성 문항·판정, 출처 URL, 정확한 인용 대조 결과와 인용 해시를 저장했다. 출제물은 원자료를 바탕으로 study-cafe가 생성·변형한 학습 예시이며 원저자의 검수·보증을 의미하지 않는다.

## 직접 확인한 문항 품질

- 천문: 위상이 생기는 이유를 월식·자체 발광과 구분했고, 보름달 뒤 밝은 부분의 감소와 상현·하현의 반대 변화 방향을 확인했다. 주관식은 증가/감소만 요구하고 그 두 항목만 채점한다.
- CSS: `border-box` 240px, 좌우 padding 20px·border 4px일 때 content 192px, padding을 30px로 바꾸면 172px가 맞다. 별도 주관식의 `content-box` 240px을 같은 외곽 크기의 `border-box`로 바꾸면 width 288px이며 margin은 포함하지 않는다. 계산·단위·margin 설명을 실제 문제에서 요구하는지도 대조했다.
- 통계: 이상값 변경 후 평균 20·중앙값 10, 짝수 개 자료의 평균 14·중앙값 9, 큰 값 추가 후 평균 50·중앙값 22.5, 주관식의 평균 12분·중앙값 6분을 다시 계산했다. 정답 보기·복수 선택·해설·채점 항목이 일치했다.

문제와 별도 정답표의 연결도 **직접 작성한 통제 자료 3개**로 실제 추출·검토했다. 각 목표에서 원문 보기, 정답 번호, 양쪽의 동일 판본 인용이 일치하고 1문항씩 사용 가능 상태가 됐다. 이 3개는 인터넷에서 찾은 기출이나 연습문제 수집 실적에 포함하지 않는다.

## 최초 실패와 수정

7차례 실행·총 **39회 호출** 중 38회는 형식에 맞는 응답을 받았고, 1회는 주관식 배점/채점 기준 형식 검사에서 거부됐다. 기존 제한 재시도로 정상 문항이 만들어졌으며 잘못된 응답은 저장하지 않았다. 38회 중에는 아래의 정상적인 ‘사용 보류’ 판단도 포함된다. 호출 대기 합은 약 **575초**였고 검색 진행 이벤트는 22개였다. 이벤트 수는 고유 검색어나 방문 페이지 수가 아니다. 이번에는 최종 제공자 오류나 429를 관찰하지 않았다.

첫 천문 통제 문항은 ‘달이 스스로 빛을 내는가?’였고, 정답·문항 번호·판본은 정확하게 추출됐다. 하지만 검토자는 좁게 정한 ‘위상의 원리·변화 순서’ 범위를 평가하지 않는다고 보류했다. 이 판단을 우회하지 않고 검증용 문제를 ‘상현달에서 보름달로 갈수록 밝은 부분이 어떻게 변하는가?’로 수정했다. 원래 보류 문항·실패 표시·판단 이유도 근거 기록에 보존했다. 따라서 처음부터 모든 단계가 한 번에 통과했다고 해석하지 않는다.

제품 수정은 다음 두 가지다.

1. 선호 자료를 수집할 수 없을 때, 같은 학습 범위에서 **다른 저자가 작성하고 사용 근거를 확인할 수 있는 자료**를 탐색하도록 공통 조사 지시를 보완했다. 통계에서 실제 대안 수집을 확인했다. 천문은 URL 보충이 필요했으므로 완전 자동 탐색 성공으로 세지 않았다.
2. 코드 점검에서 생성 중 `CODEX_RATE_LIMITED`·`CODEX_USAGE_LIMIT`·RPC 오류도 내용 오류로 취급해 3회 생성 재시도 후 ‘근거 부족’으로 표시할 수 있는 경로를 발견했다. 모든 `CODEX_*` 오류를 원래 사유로 중단하도록 수정했다. 오류별 3개 회귀 검사로 호출 1회 후 실패·문항 미저장·수동 재개 성공을 확인했다. 이번 실제 실행에서 제공자 제한 오류가 재현된 것은 아니다.

대안 자료 수집 경계 검사 1개와 위 3개를 추가해 **`pnpm check` 78/78·백엔드/프론트 타입 검사·`pnpm build` 통과**. 기존 공부방을 사용하지 않고 격리 DB에서 진행했으며 기존 답안·점수는 수정하지 않았다.

## 다른 컴퓨터에서 재현

`scripts/fixtures/material-goals.ts`의 과목·URL은 검증 데이터이며 제품 기본값이 아니다. 일반 테스트에서는 실제 Codex를 호출하지 않는다.

```powershell
# 호출 없는 사용법 확인
pnpm exec tsx scripts/live-materials.ts

# 웹 조사만 수행하고 출력된 임시 폴더를 보관
pnpm exec tsx scripts/live-materials.ts --live --phase=research

# 같은 검증 폴더에서 실제 수집된 자료로 출제·검토
pnpm exec tsx scripts/live-materials.ts --live --resume=<검증폴더> --phase=generate

# 직접 작성한 문제와 별도 정답표 연결 확인
pnpm exec tsx scripts/live-materials.ts --live --resume=<검증폴더> --phase=extract
```

- `--only=css` 등으로 목표를 한정할 수 있다. 호출 수는 실행당 기본 40회, `--max-calls=N`으로 1~100 범위에서 줄이거나 늘릴 수 있다. 최종 Codex 오류에서는 나머지 호출을 중단한다. 추가 유료 경로는 없다.
- `--rediscover`는 기존 조사 기록을 남기고 새 조사 작업을 만든다. `--refresh-scope`는 선택한 목표에 시험·추출 자료가 생기기 전에만 수정한 fixture의 범위를 반영한다. 이번 천문 URL 보충에 사용했다.
- `--refresh-control`은 기존 통제 자료·결과를 이력에 남긴 채 수정한 fixture를 새 문제/정답표로 등록한다. 이번 첫 천문 통제 문항 수정에 사용했다. 저장된 실제 문항을 덮어쓰지 않는다.
- 재개는 `materials-report.json`에 검증 표식이 있는 폴더만 허용한다. 운영 데이터 폴더를 넣지 않는다. 실행 파일을 찾지 못하면 `$env:CODEX_BIN = (Get-Command codex).Source`로 지정한다.
- 수집된 본문이 없으면 생성 검사를 중단한다. 임의 본문을 만들어 수집 성공으로 간주하지 않는다. 웹 내용·사용 조건·모델 응답은 달라질 수 있어 동일 결과를 보장하지 않는다.

이후 허용되는 실제 공개 시험/정답 PDF 한 쌍을 검증한 결과는 [PDF 추출 검증](LIVE_PDF_EXTRACTION.md)에 기록했다. 페이지를 넘는 정답 연결과 그림·수식 보존은 아직 미해결 문항이 있다. 다국어 검색의 누락, 25문항 규모의 다양성·중복, 애매하거나 긴 답안의 채점 품질도 별도 검증이 필요하다.
